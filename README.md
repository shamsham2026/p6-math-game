# 小六數學競技場

香港小學六年級數學練習／對賽網頁遊戲。**純靜態 HTML／CSS／JS**，無需後端。

## 主角：聰明鳥

答對題目，聰明鳥沿關卡前進：起跑線 → 跑道衝刺 → 跳台起跳 → 起飛 → 雲端飛翔 → 勝利峰。答錯會短暫絆倒。

## 課題

| 課題 | 說明 |
|------|------|
| 小數四則 | 小數 ＋ － × ÷（填充為主） |
| 分數四則 | 分數 ＋ － × ÷；題目用**上下堆疊分數**；答案用分子／分母輸入框 |
| 平均數 | 求平均、求未知數等 |
| 面積 | 長方形、三角形、平行四邊形、L 形 |
| 體積 | **只限長方體／正方體**（不含排水法） |
| 代數 | 化簡、代入 |
| 方程 | 解一元方程 |
| 文字題 | 混合上述課題之情境題 |
| 綜合挑戰 | 全部混合 |

### 分數答案點入？

畫面顯示堆疊分數（唔用 `a/b` 斜線）。作答時用：

- 可選「整數」框 + **分子**框 / **分母**框（上下排列）
- 接受等值分數（例如標準答案是約簡後嘅結果，未約簡但等值亦算對）
- 帶整數嘅帶分數：整數框填整數，分子分母填真分數部分

## 如何開啟

```bash
cd p6-math-game
python3 -m http.server 4173
```

開啟 `http://localhost:4173`

## 其他功能

限時計分、音效、單人／雙人對賽、`localStorage` 進度。

## iPad（約 10 吋）

已針對直向／橫向優化：`100dvh`、safe-area、緊湊 HUD／聰明鳥軌道。橫向遊戲畫面為左（進度）右（題目）雙欄，減少多餘捲動。建議用本機伺服器以 Safari 全螢幕或主畫面加入開啟。

## 雙人對坐對賽（Versus）

兩人**相對而坐**共用一部 iPad：

| 區域 | 說明 |
|------|------|
| **上半** | 玩家 A（畫面整體 `rotate(180deg)`，對佢嚟講係正立） |
| **中間** | 聰明鳥 + 兩邊正確進度條（雙方都睇到） |
| **下半** | 玩家 B（正常方向） |

### 作答規則（搶答即過）

1. **同一條題**兩邊各自顯示、各自有輸入框／鍵盤。
2. **搶答**：誰先**答對**就得分（另加 **+30 搶答分**），約 0.4 秒回饋後**即刻下一題**——唔使等對手。
3. **答錯**：嗰邊鎖定；對手仲可以繼續搶答。若兩邊都答錯，中間先出現「下一題」跳過。
4. 共用倒數計時；時間到或題目做完結算，分高者勝。

單人練習介面維持原來直向流程（唔分割）。

## 算草區

- 單人：題目下方有細畫布，可用手指／觸控筆打草稿，撳「清除」重畫。
- 雙人對坐：A／B **各自**有算草區（跟自己半邊旋轉），互唔干擾。
- 純前端 Canvas，唔會上傳。
